### 1. torch 下载卡死根因 + 修复（已闭环验证）
- 原 failure: `pipeline.status=failed:2`, `ReadTimeout` on `download-r2.pytorch.org` 拉 `torch-2.1.2+cu118`(2.326GB)。
- 真因: R2 CDN 对恒源云跨境慢/会半挂,**不是代理**(代理关掉前后整包速度都是 ~50–100KiB/s;之前 `curl -r` 测到的 1.5–2.8MB/s 是 R2 边缘缓存对头几 MB 范围请求的高速假象,不代表整包)。

### 4. 坑: SSH 自杀式 pkill

### 6. albumentations 构建墙闭环 (py39, Part A 活环境 + Part B 脚本固化)
- 根因: setup_unlanedet.sh:71 `pip install --upgrade ... setuptools ...` 升到 setuptools 82, 而 albumentations==0.4.6 的 setup.py 构建要 `pkg_resources`(setuptools>=81 已移除); 且 pip build isolation 会在隔离环境拉最新 setuptools, 与活动 env 版本无关 → 即便降 setuptools 不关隔离仍失败。
- Part A(活环境, 已验证全绿): py39 内 `pip install "setuptools<81" wheel` + `pip install --no-build-isolation -r /hy-tmp/UnLanedet/requirements.txt` + 重 pin numpy/scipy/opencv-headless/Pillow; 终 `ASSERT PASS 2.1.2+cu118 11.8 RTX 3090 albumentations 0.4.6 numpy 1.26.4 scipy 1.11.4 cv2 4.11.0 torchvision 0.16.2+cu118`。

- Part B(脚本固化, 待远端 git pull + re-run 复验): setup_unlanedet.sh 改 3 处 — (1) :71 setuptools 钉 `<81`; (2) requirements 安装加 `--no-build-isolation`; (3) headless 重 pin 后 `pip uninstall -y opencv-python` + `pip install --force-reinstall --no-deps opencv-python-headless==4.9.0.80`。
