### 1.3 目标分数 → 技术北极星的等价换算

**为什么 F1 ≈ TP 率**

- 【事实】FP = 该图预测线总数 − TP；FN = 该图真值线总数 − TP
- 若**每图预测条数 = 真值条数**，则 `预测总数 = 真值总数 = N`，故 `FP = FN = N − TP`
  → `Precision = Recall = TP/N` → **F1 = TP/N = TP 率**
- 【测算】以图均 4 条线为例：F1 = 0.83 → TP = 3.32，FP = FN = 0.68，P = R = 0.83 ✓

**TP 率 → 横向误差分布**

- 【事实】线宽 30px 无抗锯齿，等长线横向偏移 d 时 `IoU = (30−d)/(30+d)`，IoU = 0.5 → **d = 10px**
- 【测算】设单线平均横向误差服从半正态分布 |N(0, σ)|，则 `TP率 = P(X<10) = 2Φ(10/σ) − 1`

| σ（横向误差尺度） | P50 误差 | P(误差<10px) = TP 率 | 对应 F1 |
|---|---|---|---|
| 5px | 3.4px | 95.4% | 0.954 |
| 6px | 4.0px | 90.4% | 0.904 |
| **7.3px** | **4.9px** | **83.0%** | **0.830（目标）** |
| 8px | 5.4px | 78.9% | 0.789 |
| 10px | 6.7px | 68.3% | 0.683 |

**→ P0 验收指标**（见 3.1 P0-C11）：验证集单线平均横向误差 **P50 ≤ 5px**、**P(误差 < 10px) ≥ 83%**。

**条数误差的破坏力（比横向误差更致命）**

| 场景（图均 4 条线） | Precision | Recall | F1 | Δ vs 0.850 |
|---|---|---|---|---|
| 基准（TP=3.4, FP=FN=0.6） | 0.850 | 0.850 | 0.850 | — |
| 每图平均多画 0.1 条 | 0.829 | 0.850 | 0.840 | **−1.0pp** |
| 每图平均多画 0.2 条 | 0.810 | 0.850 | 0.829 | **−2.1pp** |
| 每图平均漏画 0.1 条 | 0.850 | 0.829 | 0.840 | **−1.0pp** |

**→ 规则：平均每图多/漏 0.1 条线 ≈ F1 掉 1.0pp。**
**→ P0 验收指标**：验证集「每图预测条数 = 真值条数」的图占比 **≥ 88%**（允许 12% 的图错 1 条，损失约 1.2pp）。

### 1.4 A 榜读数与 B 榜的偏差（防止误判）

- 【事实】A 榜 9 段、B 榜 10 段；段内 100 帧高度相似 → **有效独立样本量 = 段数，不是图数**
- 【测算】设段间 F1 标准差 σ_seg = 5pp（跨场景差异大，保守取值）：
  - A 榜 F1 标准误 = 5/√9 = **1.67pp**；B 榜 = 5/√10 = **1.58pp**
  - 两榜观测差值标准误 = √(1.67² + 1.58²) = **2.30pp**
- 【推测】A、B 榜视频段不同，真实难度存在系统性差异，实际偏差可达 **±3pp**

**→ 结论：A 榜 ≥ 83 才有较高把握 B 榜 ≥ 80；A 榜 ≥ 85 才谈得上 B 榜 83。**
**→ 决策规则：A 榜上 < 2pp 的波动一律视为噪声，不得据此改模型（见 4.6）。**

## 4. 关键取舍与决策点

### 4.1 算力方案

| 方案 | 供给 | 能做的事 | 代价 |
|---|---|---|---|
| **A. 纯 Kaggle 免费** | 68.6 GPU 小时（9/1–9/17，跨 3 个周配额周期） | 1 次完整训练（35.7h）+ 2 次廉价筛选（15.1h×2）≈ 65.9h，**刚好卡死** | **零容错**。一次 OOM / session 断连 / 代码 bug 即无 B 榜成绩；无法做 ablation |
| **B. 纯付费 AutoDL 4090** | 172 元 ≈ 68.8h @2.5 元/h | 4090 速度约 T4×2 的 3 倍 → 完整训练 ≈ 11.9h、筛选 ≈ 5.0h → **约 5.8 次完整训练当量** | 放弃了免费额度；需国内网络上传 9000 张数据（一次性成本） |
| **C. 混合（Kaggle 打底 + 关键时刻 4090）** | 68.6h 免费 + 付费补充 | **约 6–8 次完整训练当量**，Kaggle 与 4090 可并行跑不同实验 | 需管理两套环境；成本 150–300 元 |

**倾向：C（混合），预算 300 元。**

理由：
1. 【事实】B 榜只有一次机会，容错为零；纯免费方案的「1 次完整训练」意味着任何事故都无法挽回。
2. 【测算】4090 单 epoch ≈ 12–15 分钟（T4×2 为 45.4 分钟，按 3× 加速）→ 36 epochs ≈ 7.2–9h，**一个晚上能看到一次完整训练结果**，迭代速度决定实验次数，而实验次数是从 80 提到 83 的唯一途径。
3. 【测算】ROI：300 元 vs 奖金 2000–5000 元（且答辩占 30%，作品分高才有答辩资格）。
4. 分配建议：9/1–9/5 先花 ≈ 50 元（20h）用 4090 抢出基线（不等 Kaggle 周配额）；9/6–9/13 主用 Kaggle 免费额度跑并行 ablation；9/13–9/15 留 ≈ 80 元（32h）做最终重训与兜底。
5. 【事实】Kaggle CPU notebook **无周配额限制**（仅 12h session 上限）→ 数据解析、评测、后处理、打包校验全部放 CPU notebook，不占 GPU 额度。

### 4.2 模型路线

| 方案 | 描述 | 代价 |
|---|---|---|
| **A. 单主干精调** | 选一个主干（α-SimADNet / RVLD），全程调它 | 无对比基线，选错主干无退路 |
| **B. 多架构对比** | CLRNet-DLA34 / ADNet / RVLD 各跑一遍挑最好 | 3× 算力，纯 Kaggle 完全不够，付费方案也要 ≈ 30–36h |
| **C. 集成** | 多模型 / TTA / 后处理融合 | 训练成本高（多模型）或推理耗时长（TTA）；包体风险 |

**倾向：A 打底 + 廉价 C（只做零训练成本的 C 部分）。**

理由：
1. 【事实】CLRNet-DLA34 是 CULane 榜方法（F1@50 = 80.47），**非针对恶劣场景**；HardLane-F100 论文的 SOTA 序列 ADNet → RVLD → α-SimADNet 是同数据集上的公开水位，复现路径最短、风险最低。
2. 【推测】优先序：**α-SimADNet（83.2）> RVLD（82.0）> ADNet（80.5）> CLRNet-DLA34（跨域，80.47）**；但最终以「开源代码可得且能跑通」为硬门槛（9/2 前确认，见第 6 节 Q1）。
3. 集成的正确姿势是**先做零训练成本的部分**：TTA（P1-A16）+ 后处理（P0-C10）+ 阈值标定。**训练第二个架构是最后才考虑的事**（P1-C21）。
4. 【事实】匈牙利匹配只看几何 IoU，**车道线编号不参与评分 → 不需要 ID 分类头**；但必须预测对条数（多画一条即扣 precision，见 1.3）。这条直接决定了「集成/后处理」的优化方向是**几何质量 + 条数**，而非分类准确率。

### 4.3 是否使用跨帧时序信息

| 方案 | 收益 | 风险 |
|---|---|---|
| **A. 完全不用跨帧（纯单图推理）** | 0（基准） | 零风险，工程简单 |
| **B. 用跨帧（推理期时序聚合 / 跟踪平滑）** | 估 +1~3pp | 官方复核可能认定为违规 → **取消名次** |

**倾向：明确选 A，不做跨帧。这是对 team-lead 初步判断（收益 1–3pp）的修正。**

修正理由（关键事实被忽略）：
1. 【事实】每段视频按 **30 倍帧率下采样**抽 100 帧 → **相邻帧间隔约 1 秒**。
2. 【测算】60 km/h = 16.7 m/s → 相邻帧车辆位移约 **16.7 米**，近处地面几乎完全不重叠。
3. 【推测】RVLD / 视频类方法的时序增益建立在**连续帧（30fps，帧间位移 < 0.6m）**上；本赛题抽帧后已退化为「准静态图集」，时序先验大幅削弱，**实际收益 < 1pp，而非 1–3pp**。
4. 风险收益不对称：收益 < 1pp vs 丢掉全部奖金与名次资格。且 41 小时窗口内还要承担额外的工程复杂度。
5. **合规替代（零风险且收益相当）**：单图内的多假设融合（TTA）、B 样条平滑、几何先验约束（车道线近似平行、间距合理）——这些都在单张图内完成，不涉及任何跨图信息传递。

### 4.4 验证策略

| 方案 | 描述 | 代价 |
|---|---|---|
| **A. 单折 hold-out（按段）** | 71 段留 8–10 段 | 验证集有效样本量仅 8–10 段 → F1 波动 ±1.6–1.8pp，ablation 决策不可靠 |
| **B. K-fold（5 折）** | 全量交叉验证 | 需 5×35.7h ≈ 178h（或 107h 简化版），**算力不允许** |
| **C. 单折 + 场景分层 + 段级 bootstrap + 决策阈值** | A 的加强版 | 牺牲 11–14% 训练数据（7100 → 6300 张） |

**倾向：C，并叠加 2pp 决策阈值。**

理由与配套纪律：
1. 【事实】段内 100 帧高度相似 → 必须按段切，否则验证分虚高 3–8pp（已有踩坑共识）。
2. 【测算】验证集 8–10 段，段间 σ = 5pp → 验证 F1 标准误 = 5/√8 ≈ 1.77pp。
   → **决策规则：验证集上差异 < 2.0pp 的 ablation 结果一律视为噪声，不做决策、不提交 A 榜。**
3. 场景分层（每类 ≥ 1 段）保证验证集覆盖全部 9 类场景，避免验证集恰好全是简单场景。
4. 段级 bootstrap（P0-A02）输出 95% CI，用 **CI 下界**而非点估计做决策。
5. 【建议】若采用混合算力方案（4.1 C），可在关键 ablation 上做 **2 折交叉确认**（换一组 hold-out 段重跑筛选实验，各 5h @4090），验证结论稳定性——这是 K-fold 的廉价近似。

### 4.5 图像复原前置模块（CLAHE / 去雾 / 低光增强）

| 方案 | 收益 | 代价 |
|---|---|---|
| **A. 不做** | 0 | 低照度/雾/雨/逆光/反光/阴影 6 类场景（占 9 类中的 6 类）直接硬扛 |
| **B. 廉价 CLAHE（无学习参数）** | 估 +0.5~2pp | 单次 < 10ms（CPU）；**必须与训练同步加入**，否则训练/推理分布不一致 |
| **C. 学习式复原网络** | 估 +1~3pp（不确定） | 额外训练数据与算力（≥ 1 次完整训练当量）；复现复杂度上升；可能引入伪影 |

**倾向：B，且必须过 ablation 闸门才保留。**

理由：
1. 【事实】数据集 9 类场景中 6 类是光照/天气退化场景 → 这是主要失分来源，不容忽视。
2. 【测算】CLAHE 单次 < 10ms（CPU），训练与推理成本几乎为零，**是全表性价比最高的可选项之一**。
3. 但【推测】CNN 骨干本身对亮度变化有一定不变性，且 CLAHE 会放大噪声 → **收益不确定，必须验证**。
4. **决策闸门**：验证集段级 bootstrap，收益 **CI 下界 > +1.0pp** 才保留，否则关闭（写入 P1-C17 验收标准）。
5. **增强版建议**：若官方数据给出场景标签（或可从文件名/目录结构推断），做**场景条件化增强**——只对低照度/雾/逆光启用 CLAHE，收益更明确、副作用更小。这需要 9/2 前确认（见第 6 节 Q3）。

### 4.6 A 榜使用策略（防止过拟合 9 段）

| 方案 | 描述 | 风险 |
|---|---|---|
| **A. 把 A 榜当验证集用**（按 A 榜分选模型/调阈值） | 直接优化最终指标 | A 榜仅 9 段，有效样本量 9 → 极易过拟合；且 A 榜不计最终成绩，B 榜（10 段，不同分布）可能更差 |
| **B. A 榜只做两件事**：① 校准本地评测脚本（本地分 vs A 榜分的差值）② 端到端管线演练 | 所有决策在本地按段验证集上做 | 放弃了一部分「直接信号」 |

**倾向：B。**

理由：
1. 【测算】A 榜 F1 标准误 1.67pp（1.4 节）→ A 榜上 +0.5pp 的「提升」有极大概率是噪声。
2. 【事实】A 榜不计入最终成绩，花额度刷 A 榜是纯消耗。
3. **唯一例外**：当本地按段验证集的段级 CI 下界提升 **> 2.0pp** 时，才提交 A 榜做一次确认性验证（P1-A22 记账）。
4. A 榜的**真正价值**是校准：记录「本地验证 F1 − A 榜 F1」的差值序列，若该差值稳定，可外推预测 B 榜。
