## 0. 结论速览（先读这个）

1. **缺口**：A 榜最优 `0.73444`（记录 714962）→ 前三线 `0.79219`（9/7 快照 R3），缺口 **+5.78pp**。我方当前低于 R10（0.77199）约 3.76pp，未进 Top10。
2. **合规硬约束（本轮最重要的新确认）**：官方规则明令**测试集不得参与训练**（`docs/PRD_v1_目标84.md` §7 事实清单，来源为官方赛题页）。→ 今晨设想的 **transductive 伪标签自训练（文献 +1~3pp）默认违规，路线关闭**；只有拿到组委会书面许可才可重启。
3. **手段盘点结论**：作用在"保留哪些线"的全部手段（阈值/NMS/score-aware/几何过滤/低照度/分辨率/ConvNeXt/loss-weight/端点外推）**已穷尽且全部 NO-GO**（11 项实验）。唯一未试的合法大杠杆是 **8 折模型 ensemble + 全量 71 段重训 + 多种子**。
4. **天花板测算（诚实口径）**：ensemble +1~2pp、全量重训 +0.3~0.8pp、多种子融合 +0.5~1pp → 合规终点 A 榜 **0.755–0.775**，对应 A 榜第 5–9 名。**纯合规路径前三概率 ≈5–10%**，需要"我方融合超预期 + 对手水位停滞 + B 榜域差偏我方"三者叠加。
5. **方案结构 = 双轨**：
   - **轨 A（默认执行）合规冲刺**：A1 8 折 ensemble 主线 → A2 全量重训+多种子 → A3 B 榜交付链路保底。所有变体过 LVO 三门；A 榜最多 2 次探针。
   - **轨 B（并行，成本≈0）合规澄清**：向组委会/公告核实三条边界（测试集适配解释、B 榜规则细节、是否发布新增数据）；任一条放开才启动对应 B 轨手段。
6. **不动摇的纪律**：B 榜交付链路（冻结/沙盘/复现包）9/14 前闭环——**不进前三也要有成绩**是博弈前提；incumbent 权重与包 SHA 永久保留作为回滚锚点。

## 6. 双轨方案

### 轨 A：合规冲刺（默认执行）

#### A1 · 8 折 ensemble 主线（9/8–9/9 出验证结论）

1. **证据实验（零 A 榜额度、零污染）**：对每折 holdout，用其余 7 折模型推理→与该折单模 OOF 对比；8 折汇总 = "融合 vs 单模"的 video-disjoint 诚实评估。GPU ≈2–4h + 融合代码 ≈0.5 天。
2. **融合规则**：线级候选合并（匹配阈值内去重 + 置信度加权/择优），先用本地诊断 metric 扫参，最终裁决走冻结 Oracle；不引入无分数 union（714970 已证失败）。
3. **放行门（与 §35 三门同构）**：全局 `ΔF1 ≥ +1.0pp`；video-cluster paired bootstrap 95% CI 下界 `>0`；`≥5/8` 视频正向。**三门全过 → 进入 A2/A3 组合包；差 0.5~1.0pp → 保留为 B 榜融合包但不耗 A 榜额度；<0.5pp → 止损，回 incumbent 交付**。
4. **A 榜探针规则**：放行后最多 2 次探针（9/10–9/11）；探针 1 相对 incumbent `≥+0.5pp` 才允许探针 2；其余额度留作 B 榜前最终校准。

#### A2 · 全量 71 段重训 + 多种子（9/9 晚启动，与 A1 结论解耦）

- **主案**：4×36ep 全量 71 段（seed 42/101/202/303），生产配方不变（CULane adapted 权重 fresh 启动、同 LR schedule）；4×13h ≈52h，4090 顺序跑 9/12 晨前完成（若显存允许并行 2 路则 26h）。
- **全量模型无法本地诚实验证**（训练吞掉全部 video）——这是固有代价：靠 15ep LVO 验证过的配方 + B 榜双保险提对冲。**【假设】全量重训增益方向与 63 段→71 段数据量一致，不重标超参。**
- **终局提交物**：4 模型预测融合（沿用 A1 验证过的融合规则）作为 B 榜首提；incumbent 单模包作为校验确认提/兜底提。
- 备胎：权重 soup（若预测融合工程受阻）；多尺度 TTA（若时间富余，过同款三门）。
