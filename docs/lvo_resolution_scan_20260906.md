# LVO 分辨率方案筛选（2026-09-06）

## 结论

`960×480 + cut=0` 方案 **NO-GO**。它与生产方案 `800×320 + cut=180` 同时改变了输入分辨率、视野和纵横比，结论只适用于这套预处理组合，不能写成纯分辨率单因素因果结论。生产方案不变，继续使用 `800×320 + cut=180` 和 `t=0.50`。

## 实验协议

- 评测：同一 CLRNet-R50 36ep 权重的 8-fold LVO eval-only，7100 张图、8 个 video cluster。
- 候选：`960×480`、`cut_height=0`；基线：`800×320`、`cut_height=180`。
- 两边都使用修正后的 post-NMS 正类 softmax probability sidecar。
- 概率阈值扫描：`0.40/0.45/0.50/0.55/0.60`。
- 置信区间：video-level paired bootstrap，10,000 次，seed=42。
